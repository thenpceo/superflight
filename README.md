# SUPERFLIGHT — World Labs × Three.js

Fly like Superman through a photorealistic Gaussian-splat world generated by
[World Labs Marble](https://marble.worldlabs.ai) (`marble-1.1-plus`), rendered in the
browser with [Spark](https://sparkjs.dev) (World Labs' splat renderer for Three.js).

![world](public/assets/thumb.webp)

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:5173, click **Take Flight**.

| Input | Action |
|---|---|
| Mouse | Steer (pointer lock) |
| `W` | Fly forward |
| `Shift` | Sonic boost (FOV kick, letterbox, shake, chromatic pulse) |
| `S` | Brake |
| `Space` / `C` | Rise / dive |
| `Esc` | Release cursor |

Debug: `/?pose=1` freezes the full flight pose with an orbit camera; `/?nopost` disables post-processing.

## What's inside

- **World** — `public/assets/world.spz` (full-res splat) + `collider.glb`, generated via the
  Marble API (world id in `public/assets/world.json`). Scaled to real meters with the API's
  `metric_scale_factor`. The collider drives ground clamping, cliff wall-sliding, and
  camera occlusion.
- **Character** — Ready Player Me full-body avatar (`character.glb`) animated with the open
  [RPM animation library](https://github.com/readyplayerme/animation-library) (standing idle
  hover + falling-idle transition layer). The Superman flight pose is procedural: bone-level
  slerp targets blended on top of the mixer by speed, plus prone pitch and banked rolls.
- **Cape** — verlet-cloth simulation (7×11 grid) pinned across the shoulders, with speed-driven
  wind, travelling-ripple flutter, and a flared hem.
- **Camera** — spring-damped chase rig with speed-based FOV zoom, banked roll, layered
  procedural shake, boost impulses, and collider-aware pull-in.
- **Post** — pmndrs `postprocessing`: mipmap bloom, film grain, vignette, radial chromatic
  aberration (boost-reactive), MSAA.
- **Audio** — procedural wind (filtered pink noise) that follows airspeed; low rumble on boost.

## Regenerating the world

```bash
source .env   # WORLD_LABS_API_KEY
curl -X POST "https://api.worldlabs.ai/marble/v1/worlds:generate" \
  -H "WLT-Api-Key: $WORLD_LABS_API_KEY" -H "Content-Type: application/json" \
  -d '{"display_name":"My World","model":"marble-1.1-plus","world_prompt":{"type":"text","text_prompt":"..."}}'
# poll operations/{operation_id}, then download response.assets.splats.spz_urls.full_res
# and response.assets.mesh.collider_mesh_url into public/assets/, update world.json
# (worldScale = assets.splats.semantics_metadata.metric_scale_factor)
```
